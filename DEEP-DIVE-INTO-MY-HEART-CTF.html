1. Executive Summary

During the assessment of the target machine 10.112.175.106 running the "Hidden Deep Into My Heart" challenge, reconnaissance revealed an open SSH instance and a Werkzeug-based Python web application running on port 5000 titled "Love Letters Anonymous".

Further enumeration of the web interface exposed administrative endpoints and hidden paths through sensitive files (robots.txt), ultimately leading to administrative credentials.

3. Web Application Enumeration

Navigating to http://10.112.175.106:5000/ revealed the application title Love Letters Anonymous.

Hidden Directories & Endpoints Found

Analysis of directory structures and information disclosure files yielded the following paths:

  • /robots.txt — Disclosed restricted directory rules.
  • /cupids_secret_vault — Restricted hidden vault path found inside robots.txt.
  • /administrator — Admin login and management interface.

5. Conclusion & Recommendations

  • Disable Sensitive Indexing: Avoid leaving sensitive admin pathways such as /cupids_secret_vault inside publicly accessible robots.txt files.
  • Harden Authentication: Ensure strong password policies and implement multi-factor authentication (MFA) on the /administrator panel.
  • Werkzeug Production Warning: Werkzeug is primarily a WSGI development server; ensure a production-grade server (e.g., Gunicorn or Nginx) is used in live deployments.
