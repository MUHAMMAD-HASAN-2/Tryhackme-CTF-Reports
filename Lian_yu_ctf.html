Penetration Testing & Assessment Report: Lian Yu

Executive Summary

A comprehensive security assessment was conducted against the target system Lian Yu (10.112.146.207). The objective was to perform security enumeration, exploit exposed vulnerabilities to establish initial foothold access, and execute privilege escalation to achieve administrative (root) control.

The assessment successfully resulted in full system compromise. Initial access was obtained via weak credential management and hidden data embedded within hosted web assets using steganography. Administrative control was subsequently established due to insecure Sudo execution privileges configured for system binaries.

Phase 2: Web Enumeration & Obfuscated Data Discovery

Content discovery was executed against the HTTP service on port 80 utilizing gobuster, revealing an obfuscated directory tree.

  1. Directory bruteforcing identified the path /island.
  2. Recursive scanning underneath /island unveiled /2100/green_arrow.ticket.
  3. Inspection of green_arrow.ticket yielded an encoded string: RTy8yhBQdscX.
  4. Decoding the string via Base58 recovered the plaintext FTP password: !#th3h00d.

Phase 3: Initial Access via FTP & Steganographic Analysis

Using the recovered password alongside the user context derived from the target theme, valid FTP credentials were established.

  • FTP Username: vigilante
  • FTP Password: !#th3h00d

Upon connecting to the FTP service, the following files were exfiltrated:

Steganographic extraction was performed on the downloaded media assets using steghide with the passphrase password. This revealed two hidden files:

Phase 5: Privilege Escalation to Root

An audit of Sudo permissions for the user slade was conducted:

sudo -l

The configuration indicated that slade was authorized to execute /usr/bin/pkexec as root using sudo. Executing a shell binary via PolicyKit achieved instant root context:

sudo pkexec /bin/sh

Verifying system identity confirmed uid=0(root) gid=0(root), granting full system compromise and access to the Root Flag:

Recommended Security Hardening

  1. Remove Obfuscated Data from Web Trees: Sensitive system credentials or tokens should never be stored in readable files within public web directories.
  2. Restrict FTP Access and Implement Strong Authentication: Ensure anonymous or weak credential access is prohibited and media files containing embedded data are removed from user storage.
  3. Sudo / Privilege Policy Hardening: Review /etc/sudoers configuration. Restrict execution privileges on powerful binaries such as pkexec, which allow interactive shell invocation (/bin/sh or /bin/bash).
  4. Upgrade Legacy OS & Software Versions: Debian 8 (Jessie) and legacy versions of OpenSSH/vsftpd are end-of-life and present additional unpatched vulnerabilities. Upgrading to a supported operating system branch is strongly advised.
